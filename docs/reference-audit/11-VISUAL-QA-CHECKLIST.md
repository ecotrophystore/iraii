# 11 — Visual QA Checklist

Use this checklist when comparing the IRAI build against the audit screenshots. Items marked **(audit)** have evidence in this audit; others are not yet verified on the reference.

## Global
- [ ] Announcement bar present, single line, arrows visible. **(audit)**
- [ ] Sticky header with logo left or centered per breakpoint. **(audit)**
- [ ] Footer link groups match structure: Help, Shop, Company, social, locale, legal. **(audit)**
- [ ] No horizontal scroll at 320 px. **(audit, visual only)**

## Homepage
- [ ] Hero shows one H1, eyebrow, two CTAs. **(audit)**
- [ ] Hero image art-directed at tablet and mobile. **(audit)**
- [ ] Four category tiles; desktop 4-up, mobile 2-up. **(audit)**
- [ ] Best Sellers carousel with prev/next. **(audit)**
- [ ] Promo tile row. **(audit)**
- [ ] Three editorial value blocks. **(audit)**
- [ ] Floating assistant does not cover primary CTAs on mobile. **(audit)**

## Collection
- [ ] Breadcrumb, hero with title and description. **(audit)**
- [ ] Filter button with product count and Men/Women toggle. **(audit)**
- [ ] Sort options (eight). **(audit)**
- [ ] Badges: NEW, FINAL FEW, BESTSELLER, SALE, WATERPROOF. **(audit)**
- [ ] Sale items show two prices. **(audit)**

## Product
- [ ] Gallery with thumbnails. **(audit, partial)**
- [ ] Price with shipping tag. **(audit)**
- [ ] Color selector grouped by variant type. **(audit)**
- [ ] Size grid with unavailable sizes. **(audit)**
- [ ] Disabled "Select a size" CTA until size chosen. **(audit)**
- [ ] Accordions: Why, Materials, Care. **(audit)**

## Search and cart
- [ ] Results count line and Products or Articles tabs. **(audit)**
- [ ] Cart empty state with shortcut buttons. **(audit)**
- [ ] Free-shipping progress line. **(audit)**
